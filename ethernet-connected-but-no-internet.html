Ethernet Connected But No Internet

Ethernet problems feel especially confusing because wired connections are supposed to be the reliable fallback. When Ethernet says connected but nothing loads, it usually means the physical link is alive while something higher up in the path is still broken.

Quick answer

Separate cable-link success from actual internet access

Quick answer

If Ethernet shows connected but the internet does not work, start by checking whether the problem affects multiple devices. Then work through IP, DNS, cable, port, and router checks before you assume the Windows adapter is broken.

Common causes

Common causes of connected Ethernet with no internet

  • Router or modem lost internet access
  • Bad IP lease or DHCP trouble
  • DNS server problems
  • Defective cable or bad router port
  • Windows adapter settings or driver issues

In support cases, one of the most common surprises is that the Ethernet link light is fine even though the router itself is what actually lost internet.

Troubleshooting flow

Step-by-step wired network troubleshooting

  1. Test another device or another port if possible.
  2. Swap the Ethernet cable. Bad cables do happen.
  3. Restart the router and modem if several devices are affected.
  4. Refresh the network connection on the PC. Restart Windows or renew the connection cleanly.
  5. Check DNS next. If the link looks alive but websites fail, go to the DNS Server Not Responding guide.

If Wi-Fi and Ethernet both fail the same way, the problem is usually bigger than the adapter itself.

If the Ethernet link itself keeps dropping, use Ethernet Keeps Disconnecting in Windows 11. If Windows identifies the connection but browsers alone will not load sites, use Ethernet Connected but Websites Not Loading.

When hardware may be involved

When hardware is the stronger suspect

Hardware becomes more likely when different cables and ports do not change anything, the Ethernet adapter throws repeated errors, or the connection drops even on a known-good network. That is when it makes sense to suspect the NIC, dock, or router hardware rather than just Windows settings.

Professional help

When to get outside help

Call the ISP if both wired and wireless devices lose internet after normal restarts. Get local repair help if only one PC fails and the Ethernet adapter keeps misbehaving across known-good cables and ports.

FAQ

Why does Ethernet say connected but there is no internet?

That usually means the cable link is active but the laptop still cannot reach the internet. DNS trouble, bad IP information, router problems, modem issues, or adapter settings are common causes.

How do I know if Ethernet or the router is the problem?

Test another device or another port if you can. If several wired devices fail, the router or modem is the stronger suspect. If only one Windows machine fails, focus on that PC first.

Can DNS problems affect Ethernet too?

Yes. DNS issues can break website access on Ethernet the same way they do on Wi-Fi, even while the connection still looks active.

Should I reset the network adapter right away?

Not first. Basic checks like cable, router, modem, DNS, and IP refresh are usually better starting points than jumping straight to full network reset.

When is hardware more likely to be the cause?

Hardware becomes more likely if different cables and ports do not help, the Ethernet adapter keeps throwing errors, or the link drops under light use with no clear software pattern.

When should I call my ISP about Ethernet with no internet?

Call the ISP if both wired and wireless devices lose internet after router and modem restarts, because the issue is likely outside the PC at that point.
