External storage guide

External Hard Drive Not Showing Up in Windows?

If an external hard drive or external SSD disappears from File Explorer, start with the simple physical checks before you touch formatting, partitions, or recovery tools. A surprising number of cases come down to power, cables, hubs, or drive letters rather than total drive failure.

Quick answer

Check power, cable, and detection path first

Quick answer

Try another USB port, avoid hubs, test another cable, and then check File Explorer, Disk Management, and Device Manager in that order. Do not format a drive early if it may contain important data.

Physical checks

Use another USB port, and be careful with hubs

External drives are more sensitive to weak ports and flaky hubs than many people realize. Plug the drive directly into the laptop if possible. If you are already using a hub or dock, remove it from the test for now.

  1. Try another USB port. Especially a port on the laptop itself.
  2. Avoid hubs and adapters for the first check. They can cause power or communication issues.
  3. Try another cable. Cables fail more often than people expect.

Power behavior

Listen and feel for activity

A mechanical external hard drive often gives clues. You may hear it spin up, feel light vibration, or hear unhealthy clicking. An external SSD is quieter, so you may only notice a power light or heat building slightly.

If the drive never powers up consistently, think about cable, port, enclosure, or power delivery before you assume Windows is the main problem.

Windows checks

File Explorer, Disk Management, and missing drive letters

File Explorer is only the first layer. A working external drive may still stay hidden there if Windows has not assigned a drive letter or if the disk state is odd.

  1. Check File Explorer. Look under This PC.
  2. Open Disk Management. Look for the drive by size, even if it has no letter.
  3. Assign a drive letter if needed. That alone can restore visibility in Explorer.

Drivers

Device Manager and USB controller issues

If the drive vanishes from Explorer and Disk Management, Device Manager becomes the next stop. Look for warning icons under Disk drives or Universal Serial Bus controllers. A USB controller issue can make a healthy drive look dead.

If several USB devices have been acting strangely, the broader USB Device Not Recognized in Windows guide may also help.

Test elsewhere

Trying another computer is a very useful reality check

If the drive behaves the same way on a second Windows PC, the drive, enclosure, or cable becomes much more suspicious. If it works fine there, your original laptop is the better place to keep troubleshooting.

Data safety

RAW, unallocated, or format prompts need caution

If the drive shows as RAW, unallocated, or Windows suddenly asks to format it, stop if the files matter. Those prompts can appear when the partition or file system is damaged, and formatting too early can make recovery harder.

If the drive is new and empty, setup may be normal. If it used to contain important files, treat it as a data-recovery decision, not just a storage setup decision.

Failure warnings

Clicking, repeated disconnects, or access errors are bigger red flags

Clicking, repeated connect-disconnect sounds, extremely slow access, or error messages while copying files are stronger warnings than a simple missing drive letter. If the data matters, minimize repeated attempts and consider professional recovery sooner rather than later.

If the missing device is the laptop's internal storage instead, use SSD Not Showing Up in Windows 11. If the external drive appears but performance is awful, SSD Slow in Windows 11 may be the better next read for an external SSD case.

FAQ

External hard drive not showing up FAQ

Why is my external hard drive not showing up in Windows?

The most common causes are cable issues, power problems, hub issues, missing drive letters, driver trouble, or a failing drive. Start with the simple physical checks before you touch formatting.

What should I check first when an external drive is missing?

Try another USB port, remove any hub from the chain, and test another cable. Then check Disk Management to see whether Windows can detect the drive at a lower level.

Can a missing drive letter stop an external drive from appearing?

Yes. The drive may be working but still stay hidden in File Explorer until Windows assigns it a letter.

Should I format an external drive if Windows asks me to?

Not if it contains important files. Unexpected format prompts can be a warning sign, not a suggestion you should accept right away.

What if the external drive keeps disconnecting or clicking?

That is more serious than a simple visibility issue. If the data matters, reduce repeated attempts and think about professional recovery.

When should I test the external drive on another computer?

As soon as you have checked the cable and port. It is one of the quickest ways to separate a drive problem from a Windows problem.
