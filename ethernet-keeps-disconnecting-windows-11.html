Ethernet Keeps Disconnecting in Windows 11?

Intermittent Ethernet loss is different from a connection that stays up but has no internet. First find out whether the cable link itself drops, then isolate the cable, router port, PC adapter, and Windows settings.

Physical path

Test the cable and network port before changing Windows

  1. Try a known-good Ethernet cable. Inspect both latches and connectors.
  2. Move to another router or switch port. A single bad port can mimic an adapter fault.
  3. Test another device on the same cable. This separates the cable and network side from the PC.
  4. Check USB Ethernet adapters and docks. Connect directly where possible.

Windows checks

Check the adapter, power settings, and driver timing

In Device Manager, inspect the Ethernet adapter for a warning icon and note whether the issue began after a Windows update. Review its power-management setting if drops cluster around sleep or idle time. Update or roll back drivers based on the timing, using the driver update guide as a safe reference.

Speed and duplex should normally remain on Auto Negotiation. Only test a different supported setting when both ends are known compatible and a cable or port test did not help.

Hardware warning

When this is probably a hardware problem

An adapter that drops on multiple networks with multiple cables and router ports is more suspicious. A port with no link light, a USB adapter that disconnects itself, or an adapter that disappears from Device Manager also point toward hardware.

If Ethernet stays connected but sites do not load, use Ethernet Connected but Websites Not Loading instead.

FAQ

Ethernet disconnecting FAQ

Why does Ethernet keep disconnecting in Windows 11?

A damaged cable, loose router port, USB Ethernet adapter, power management, driver issue, link negotiation problem, or failing network hardware can cause dropouts.

Can a bad Ethernet cable cause intermittent disconnects?

Yes. Replacing the cable with a known-good one is one of the quickest and most useful tests for intermittent wired dropouts.

Can Windows power management disable Ethernet?

It can contribute, especially after sleep. Check cable and port first, then review the adapter power-management settings.

When is an Ethernet adapter likely failing?

Hardware is more likely when the adapter disconnects with multiple cables and network ports, disappears in Device Manager, or fails on a second network.
