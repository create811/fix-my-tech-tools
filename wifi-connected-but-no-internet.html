Wi-Fi troubleshooting guide

Wi-Fi Connected But No Internet

This is one of the most misleading Windows network problems because the Wi-Fi icon looks fine even though nothing loads. In real support work, that usually means the laptop still sees the router, but the path from the router to the internet is broken somewhere.

Quick answer

Start by checking whether the problem affects one device or everything

Quick answer

If multiple devices on the same Wi-Fi have no internet, the router, modem, or ISP is the better place to look. If only one Windows laptop is affected, start with DNS, IP refresh, and adapter checks before using bigger reset options.

Common causes

Common causes of connected Wi-Fi with no internet

  • Router or modem lost internet access
  • DNS server issues
  • IP address conflicts or a bad DHCP lease
  • Temporary Windows adapter glitches after sleep or updates
  • Browser loading problems that look like network failure

One common real-world pattern is the laptop waking from sleep, showing Wi-Fi connected, and then quietly failing to load anything until the adapter is refreshed.

Troubleshooting flow

Step-by-step troubleshooting that starts safe

  1. Check another device on the same Wi-Fi. This tells you whether the problem is local or network-wide.
  2. Restart the router and modem if everything is affected.
  3. Forget and reconnect to the Wi-Fi network if only one laptop is affected.
  4. Refresh the connection. Toggle Wi-Fi off and back on, or restart the laptop cleanly.
  5. Check DNS next. If websites fail but the network still shows connected, use the DNS Server Not Responding guide.

If the real issue is that Wi-Fi drops on and off rather than staying connected with no internet, the Windows 11 Wi-Fi Keeps Disconnecting guide is the better match.

When hardware may be involved

When hardware becomes more likely

Hardware is more likely when Wi-Fi behaves badly on every network, the adapter disappears from Windows, or the laptop only stays online with the lid in certain positions. If the wireless adapter itself keeps failing, software fixes start helping less and less.

Professional help

When to stop troubleshooting on your own

Get outside help if the issue affects all devices and keeps coming back after router restarts, or if the laptop is the only device affected but the Wi-Fi adapter keeps disappearing, throwing driver errors, or failing across multiple networks. At that point you are either dealing with ISP trouble or a weakening adapter.

FAQ

Why does Wi-Fi say connected but there is no internet?

That usually means your laptop is still talking to the router, but something between the router and the internet is failing. DNS issues, modem trouble, IP conflicts, router glitches, and ISP outages are common reasons.

How do I know if the problem is my laptop or the router?

Check whether other devices on the same Wi-Fi also lose internet. If every device has the same problem, focus on the router, modem, or ISP first. If only one laptop is affected, start with Windows network checks.

Can DNS problems make Wi-Fi connected but no internet appear?

Yes. DNS problems are one of the most common reasons websites stop loading even though Wi-Fi still shows connected.

Should I run Network Reset right away?

Usually no. Network Reset is useful later, but it removes saved network settings. It makes more sense after basic checks like rebooting the router, testing other devices, and checking DNS have already failed.

When is hardware more likely to be the cause?

Hardware becomes more likely if Wi-Fi works only at certain angles, disappears completely, fails across many different networks, or keeps breaking after normal software troubleshooting.

Should I call my ISP if Wi-Fi is connected but there is no internet?

Yes, if multiple devices are affected and the router or modem reboot does not help. At that point the issue is often outside the laptop.
