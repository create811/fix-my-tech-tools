External storage guide

External Drive Showing in Disk Management but Not File Explorer?

If Disk Management can see the external drive, Windows has detected it at a lower level. That is useful information: the next step is to read the disk's exact state, not to format it blindly.

First result

Look for a missing drive letter

Find the correct volume by its size. If it is Healthy, has a normal file system, and has no letter, right-click that volume and choose Change Drive Letter and Paths. Assign an unused letter. This is the usual safe fix when File Explorer is the only place the drive is missing.

Do not change a volume until you have identified the correct disk; disconnect other removable drives first if the list is confusing.

Disk state

Offline, RAW, and unallocated each mean something different

  • Offline: If you recognize the disk and it looks otherwise healthy, bring it online.
  • Healthy volume without a letter: Assign a letter.
  • RAW: Windows cannot read the expected file system. Do not format if files matter.
  • Unallocated: A new empty drive may need setup; a used drive may need recovery instead.

A partition Windows cannot read may not be a drive-letter issue, and formatting it can remove evidence needed for recovery.

Safe next steps

When not to format the drive

Do not initialize, delete partitions, create a new volume, or format an external drive that previously held important data just because Explorer cannot open it. First test the cable and another computer, then decide whether the files justify data-recovery help.

If Windows detects the disk but gives an access error after it gets a letter, use External Hard Drive Not Accessible in Windows.

Hardware warning

When this is probably a hardware problem

A Disk Management entry does not prove the drive is healthy. Repeated disconnects, extreme slowness, clicking from an HDD, or a drive that changes size unexpectedly can indicate an enclosure, cable, or drive failure. Reduce repeated attempts when data is important.

FAQ

Disk Management but not File Explorer FAQ

Why does my external drive show in Disk Management but not File Explorer?

The most common reason is a missing drive letter, but an offline disk, unsupported partition, RAW file system, or unallocated space can also keep it out of File Explorer.

Is it safe to assign a drive letter in Disk Management?

Assigning an unused letter to a healthy existing volume is normally non-destructive. Verify the disk by size before changing anything.

Should I format a RAW external drive?

Not if it contains needed files. RAW can indicate file-system damage, and formatting can make recovery harder.

What does unallocated mean for a used external drive?

It can mean Windows cannot see a partition. Treat a previously used drive as a recovery case instead of creating a new volume immediately.
