Windows 11 network guide

Ethernet Unidentified Network in Windows 11?

An Unidentified Network message usually means the cable link exists but Windows did not get enough usable network information to identify and use the connection normally. Start with the cable and router, then inspect the IP details Windows received.

Basic checks

Check whether the problem is one PC or the network

  1. Try another Ethernet cable and router or switch port.
  2. Check a second wired device if you can. Multiple failures make the router more likely.
  3. Restart the router only if it is safe to interrupt the network. Then wait for it to finish starting.
  4. Check the network profile. Use Private only on a trusted home or work network.

IP details

Use ipconfig to see what Windows received

Open Command Prompt and run ipconfig. Under Ethernet, check whether there is a normal IPv4 address and a Default Gateway. An address beginning 169.254 often means the PC did not receive an address from DHCP. A blank gateway can also explain why the network stays unidentified.

If this is the exact “doesn't have a valid IP configuration” error, use Ethernet Doesn't Have a Valid IP Configuration for the focused recovery sequence.

Adapter checks

Refresh the adapter before a full reset

Disable and re-enable the Ethernet adapter once, then check Device Manager for a warning icon. A driver update may help when the timing points to an update or new adapter. A full Network Reset is a later option because it reinstalls adapters and can clear settings; do not use it as the first response.

FAQ

Ethernet unidentified network FAQ

Why does Windows 11 show Ethernet as an unidentified network?

Windows often shows Unidentified Network when the adapter cannot obtain or use normal DHCP, gateway, or network profile information.

How can I check my Ethernet IP address and gateway?

Open Command Prompt and run ipconfig. Look at the Ethernet adapter's IPv4 Address and Default Gateway, then compare with a working device if available.

Should I use Network Reset for an unidentified Ethernet network?

Use Network Reset later, after cable, router, DHCP, adapter, and driver checks. It removes and reinstalls network adapters and can remove saved settings.

Can a router cause an unidentified Ethernet network?

Yes. A router's DHCP service, a bad LAN port, or a broader router fault can stop a PC receiving usable network details.
