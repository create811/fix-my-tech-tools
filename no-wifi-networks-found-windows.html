No Wi-Fi Networks Found in Windows

When Windows suddenly says there are no Wi-Fi networks at all, the problem is usually lower-level than a weak signal. In real support cases, this often comes down to a disabled adapter, a driver issue, airplane mode, or a wireless card that is not behaving the way Windows expects.

Quick answer

First make sure the Wi-Fi adapter is actually on and visible

Quick answer

If no Wi-Fi networks appear at all, start by checking airplane mode, function-key wireless toggles, and whether the Wi-Fi adapter still appears in Windows. If the adapter is missing or erroring out, driver or hardware trouble becomes much more likely.

Common causes

Common causes of missing Wi-Fi networks

  • Airplane mode or a hardware wireless toggle
  • Disabled or crashed Wi-Fi adapter
  • Driver damage after updates or wake issues
  • Wireless services not starting properly
  • Failing Wi-Fi hardware

On some laptops, a keyboard shortcut can disable wireless so cleanly that Windows looks like it simply cannot see any networks.

Troubleshooting flow

Step-by-step checks that come before deeper resets

  1. Check airplane mode and wireless function keys.
  2. Restart the laptop cleanly. This can bring back an adapter that got stuck after sleep or an update.
  3. Open Device Manager. Check whether the Wi-Fi adapter is present, disabled, or showing a warning icon.
  4. Check Windows Wi-Fi services. If the adapter is present but no networks show, services are worth checking before bigger steps.
  5. Update or roll back the Wi-Fi driver if the timing fits.

If the laptop does see networks but keeps dropping them, go to the Windows 11 Wi-Fi Keeps Disconnecting guide instead.

When hardware may be involved

When the wireless card itself becomes the stronger suspect

Hardware becomes much more likely if the adapter disappears completely, returns only after shutdowns, or behaves the same on every network and after clean driver work. That is especially true on older laptops that have already had weak Wi-Fi for a while.

Professional help

When to seek professional help

Get help if Device Manager keeps losing the adapter, if the laptop cannot see any Wi-Fi even after safe driver work, or if the card shows repeated hardware errors. At that point you are beyond ordinary settings and restart fixes.

FAQ

Why does Windows say no Wi-Fi networks found?

That usually points to a disabled Wi-Fi adapter, airplane mode, driver trouble, a stopped wireless service, or a hardware problem that keeps Windows from seeing nearby networks.

Can airplane mode or a keyboard switch hide all Wi-Fi networks?

Yes. Some laptops still use function keys or hardware toggles that disable wireless completely, which makes it look like no networks exist.

Should I reinstall the Wi-Fi driver if no networks appear?

If the adapter is present but not working correctly, driver reinstall or rollback can help. If the adapter is missing entirely, look at Device Manager first before making bigger changes.

How do I know if the Wi-Fi card itself is failing?

If the adapter keeps disappearing, fails on multiple networks, or behaves the same after normal software troubleshooting, hardware becomes much more likely.

Can a Windows update cause no Wi-Fi networks found?

Yes. Windows updates sometimes change wireless drivers or power settings in ways that leave the adapter disabled or unstable.

When should I get professional help for missing Wi-Fi networks?

Get help if the adapter vanishes repeatedly, Device Manager shows persistent errors, or the laptop still cannot see any networks after safe checks and driver troubleshooting.
