Network Adapter Not Showing in Windows 11?

If Ethernet or Wi-Fi has disappeared from Windows entirely, this is a device-detection problem, not an ordinary no-internet problem. First identify which adapter is missing, then check Device Manager and the driver path.

Identify the missing device

Ethernet and Wi-Fi are separate adapters

Check whether only Ethernet is missing, only Wi-Fi is missing, or both are gone. A missing wired adapter may still leave Wi-Fi working, while a Wi-Fi failure needs a different path such as No Wi-Fi Networks Found in Windows.

Device Manager

Look for disabled, hidden, or error-state adapters

  1. Open Device Manager and expand Network adapters.
  2. Choose View, then Show hidden devices. A faded entry may reveal a prior device state.
  3. Enable a disabled adapter. Do not uninstall hardware randomly.
  4. Check for warning icons or Unknown devices. These often point to a driver issue.
  5. Check Windows Update and the PC maker's driver. Use the driver guide for the safe order.

Hardware path

Check external adapters and firmware only when relevant

For a USB Ethernet adapter, try a different direct USB port and cable or dock arrangement. If the built-in adapter is absent even before Windows loads, or it never appears after driver checks, review BIOS or UEFI settings for an enabled onboard LAN or wireless option. Avoid changing unrelated firmware settings.

When this is probably a hardware problem

Hardware is more likely when the adapter is absent from Device Manager after driver and update checks, a USB adapter fails on multiple PCs, or both wired and wireless hardware disappear following physical damage or a motherboard issue.

FAQ

Network adapter not showing FAQ

Why is my network adapter not showing in Windows 11?

It may be disabled, hidden, missing its driver, affected by an update, disabled in BIOS or UEFI, disconnected if external, or failing in hardware.

How do I find a hidden network adapter in Device Manager?

Open Device Manager, choose View, then Show hidden devices, and expand Network adapters to inspect disabled or faded entries.

Is a missing Ethernet adapter different from a missing Wi-Fi adapter?

Yes. They are separate devices and drivers. Confirm whether Ethernet, Wi-Fi, or both are absent before selecting the next troubleshooting step.

Can BIOS or UEFI settings hide a network adapter?

Yes. Some computers allow onboard LAN or wireless hardware to be disabled in firmware, although driver and Windows checks are usually easier first.
